# Sistema de Gestión de Procesos — ED C2-1

Base parcial en C++98 para gestionar procesos con estructuras dinámicas lineales. La lista didáctica de `version_para_equipo/main.cpp` permite insertar, buscar, eliminar y mostrar procesos. La cola, la pila y la persistencia están en integración; el proyecto todavía no es una entrega final completa.

## Compilar

```sh
g++ -std=c++98 -Wall -Wextra -pedantic version_para_equipo/main.cpp -o avance
./avance
```

`include/` contiene el PCB y los contratos de integración. Los documentos de planificación, guías y borradores del informe se guardaron en [Google Drive].
